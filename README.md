# Daraz Automation with Selenium Python (POM)

## 📌 Project Description
This is a Selenium automation project for the Daraz website using Python, Pytest, and the Page Object Model (POM) design pattern.

## 🛠 Technologies Used
- Python
- Selenium
- Pytest
- WebDriver Manager
- Page Object Model (POM)

## 📂 Project Structure

```
Daraz_Automation/
│── pages/
│   └── home_page.py
│── testcases/
│   └── test_search.py
│── conftest.py
│── requirements.txt
│── README.md
```

## ✅ Features
- Open Daraz website
- Search for a product
- Click the Search button
- Verify the page title

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/Trisha-SWE/Daraz_Automation.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the tests

```bash
pytest -v
